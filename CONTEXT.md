# Rich Text Editor

A React-based rich text editor built on TipTap, styled with shadcn/ui.
Provides a modern editing experience with a toolbar-based interface and
light/dark theme support.

## Editor Concepts

**Editor**: The top-level editing surface. Composed of TipTap extensions
and a toolbar. Not a contenteditable div itself — TipTap manages that.

**Extension**: A TipTap module that adds behavior to the editor. Can be
an official TipTap extension or a custom one in `src/extensions/`.
Extensions can add nodes, marks, commands, keyboard shortcuts, or
entire UI features.

**Mark**: Inline text formatting applied to ranges of text. Examples:
bold, italic, underline, text color, highlight.

**Node**: A block-level element in the document. Examples: paragraph,
heading, list item, code block, image.

**Toolbar**: The horizontal bar above the editor containing format
buttons. Each button is a small React component in `src/components/editor/`
that reads and mutates editor state via the TipTap editor instance.

**Image Placeholder**: A temporary node shown while an image is being
uploaded. Replaced with the real image node once upload completes.

**Find and Replace**: The feature that searches document text for a
query and optionally replaces matches. Uses the official TipTap
find-and-replace extension for logic; UI is custom-built with shadcn
components.

## UI Concepts

**shadcn/ui components**: Reusable UI primitives (Button, Popover,
Dialog, etc.) generated by the shadcn CLI and placed in
`src/components/ui/`. These are copy-paste components, not a library —
they belong to the project.

**Theme**: The visual appearance of the app. Two built-in themes: light
and dark. Switched via a theme toggle in the UI. Implemented with CSS
variables on the `:root` and `.dark` selectors.

_Avoid_: Skin, mode, color scheme
